本章按“性能指标 → 总线事务 → 总线定时 → 考前速记”整理。复习时重点掌握频率与周期的区别、总线带宽计算、突发与非突发传输的差异，以及同步定时与异步定时的对比。

<Tip>
  本章的四条主线：时钟频率看时钟周期，工作频率看总线传输周期；带宽 = 总线宽度 × 每秒有效传输次数；突发传输只传一次起始地址；同步定时靠统一时钟，异步定时靠握手信号。
</Tip>

## 总线性能指标

<AccordionGroup>
  <Accordion title="常见性能指标">
    | 性能指标 | 含义 |
    | --- | --- |
    | 总线传输周期 | 完成一次总线传输操作所需的时间 |
    | 总线工作频率 | 总线每秒完成的传输次数，通常为总线传输周期的倒数 |
    | 总线时钟周期 | 总线时钟信号的一个周期 |
    | 总线时钟频率 | 总线时钟信号每秒的周期数 |
    | 总线宽度 | 数据总线一次能够传输的数据位数 |
    | 总线带宽 | 单位时间内总线能够传输的最大数据量 |
    | 总线复用 | 同一组信号线在不同时间传输不同的信息 |
    | 信号线数 | 地址线、数据线、控制线等信号线的总数 |
  </Accordion>

  <Accordion title="时钟频率与工作频率">
    这是本节的重点辨析。

    | 对比项 | 总线时钟频率 | 总线工作频率 |
    | --- | --- | --- |
    | 含义 | 时钟信号每秒完成的周期数 | 总线每秒完成的传输次数 |
    | 计算公式 | $f_{\text{时钟}}=1/T_{\text{时钟}}$ | $f_{\text{工作}}=1/T_{\text{总线}}$ |
    | 决定因素 | 时钟周期 | 总线传输周期 |
    | 两者关系 | 不一定等于总线工作频率 | 不一定等于总线时钟频率 |

    例：总线时钟周期为 $10\text{ ns}$，总线传输周期为 $30\text{ ns}$。

    $$
    f_{\text{时钟}}=\frac{1}{10\text{ ns}}=100\text{ MHz}
    $$

    $$
    f_{\text{工作}}=\frac{1}{30\text{ ns}}\approx33.3\text{ MHz}
    $$

    <Info>
      记忆：时钟频率看时钟，工作频率看传输。一个总线传输周期可能包含多个时钟周期，因此二者不一定相等。
    </Info>
  </Accordion>

  <Accordion title="总线带宽">
    总线带宽反映单位时间内能够传输的数据量。

    若每个总线传输周期传输一个数据块，则：

    $$
    B=W\times f_{\text{工作}}
    $$

    这里 $W$ 以 bit 为单位时，计算结果为 bit/s。若要求 B/s，则：

    $$
    B=\frac{W}{8}\times f_{\text{工作}}
    $$

    例：总线宽度为 32 bit，工作频率为 20 MHz，每个传输周期传输一次数据。

    $$
    B=\frac{32}{8}\times20\times10^6=80\text{ MB/s}
    $$

    <Warning>
      如果题目涉及突发传输，要根据每次事务实际传输的数据量计算，不能默认每个事务只传输一个数据块。
    </Warning>
  </Accordion>
</AccordionGroup>

## 总线事务

总线事务是指完成一次总线信息交换所涉及的操作过程。

<AccordionGroup>
  <Accordion title="总线事务的三个阶段">
    地址传送阶段 → 从设备响应阶段 → 数据传送阶段。

    1. **地址传送阶段**：主设备给出目标地址及相关控制信息。
    2. **从设备响应阶段**：从设备识别地址并对主设备的请求作出响应。
    3. **数据传送阶段**：主设备与从设备之间进行实际的数据交换。

    | 阶段 | 核心任务 |
    | --- | --- |
    | 地址传送阶段 | 确定访问目标 |
    | 从设备响应阶段 | 识别请求并作出响应 |
    | 数据传送阶段 | 完成数据交换 |
  </Accordion>

  <Accordion title="非突发传输与突发传输">
    这是总线事务中的重要考点。

    **非突发传输（非猝发传输）**

    在每个传送周期内，都先传送地址，再传送数据，主从设备之间通常每次传输一个字长的数据。

    特点：

    - 每次传输都需要传送地址。
    - 通常每次传送一个数据字。
    - 连续传输多个数据时，需要重复地址传送等操作。
    - 控制过程相对简单，但连续传输时效率较低。

    **突发传输（猝发传输）**

    先传送一个起始地址，然后连续进行多次数据传输，即一次传输一个地址和一批地址连续的数据。

    特点：

    - 只需先传送起始地址。
    - 随后连续传输多个数据。
    - 多个数据通常对应连续的地址。
    - 减少重复传送地址的开销，提高连续数据传输的效率。
    - 常见于主存与 Cache 之间的连续数据块传输。
  </Accordion>

  <Accordion title="非突发与突发传输对比">
    | 对比项 | 非突发传输 | 突发传输 |
    | --- | --- | --- |
    | 地址传送 | 每次传输均需传送地址 | 通常只需传送起始地址 |
    | 数据传输 | 通常一次传输一个字 | 连续传输多个数据字 |
    | 地址连续性 | 不要求连续 | 通常为连续地址 |
    | 控制开销 | 相对较大 | 相对较小 |
    | 连续数据传输效率 | 较低 | 较高 |

    <Tip>
      记忆口诀：非突发——一个地址、一次数据、重复寻址；突发——一个起始地址、连续多个数据、减少开销。
    </Tip>
  </Accordion>
</AccordionGroup>

## 总线定时

总线定时是指总线通信双方在交换数据时，对时间配合关系进行控制的方式。主要分为同步定时和异步定时。

<AccordionGroup>
  <Accordion title="同步定时方式">
    采用统一的时钟信号协调发送方和接收方的传输时序。

    特点：

    - 使用统一时钟信号。
    - 各部件按照规定的时钟节拍工作。
    - 控制逻辑简单，时序明确。
    - 对设备之间的时序配合要求较高，慢速设备可能需要等待周期。

    <Info>
      记忆：统一时钟、固定节拍、控制简单。
    </Info>
  </Accordion>

  <Accordion title="异步定时方式">
    不依赖统一时钟确定每一步操作的时刻，而是通过请求、应答等握手信号协调传输双方。

    基本过程：

    1. 主设备发出请求信号。
    2. 从设备收到请求并进行处理。
    3. 从设备发出应答信号。
    4. 双方根据握手规则撤销相应信号，完成传输。

    特点：

    - 通过握手信号控制传输时序。
    - 能够适应不同速度的设备。
    - 传输时间灵活。
    - 控制过程相对复杂，存在握手开销。

    <Info>
      记忆：请求应答、握手协调、时间灵活。
    </Info>
  </Accordion>

  <Accordion title="异步定时的三种互锁方式">
    | 方式 | 信号配合关系 | 特点 |
    | --- | --- | --- |
    | 不互锁 | 双方均不等待对方撤销信号后再继续 | 双方不相互等待 |
    | 半互锁 | 一方等待对方的相应信号，另一方不等待 | 单向互锁 |
    | 全互锁 | 双方均等待对方完成相应的信号撤销 | 双向互锁 |

    具体理解：

    - **不互锁**：主设备发出请求后，经过规定时间即可撤销请求；从设备发出应答后，也可经过规定时间撤销应答，不必等待对方撤销信号。
    - **半互锁**：主设备等待从设备应答后才撤销请求；从设备不必等待主设备撤销请求，便可撤销应答。
    - **全互锁**：主设备收到应答后撤销请求；从设备检测到请求撤销后，再撤销应答。

    <Warning>
      易错：半互锁是“单向等待”，不是双方都不等待；全互锁才是双向等待。
    </Warning>
  </Accordion>

  <Accordion title="同步定时与异步定时对比">
    | 对比项 | 同步定时 | 异步定时 |
    | --- | --- | --- |
    | 时间基准 | 统一时钟 | 握手信号 |
    | 控制方式 | 时钟节拍控制 | 请求与应答控制 |
    | 传输时间 | 由规定时序决定 | 根据设备响应确定 |
    | 设备适应性 | 需要满足时序要求 | 适应不同速度设备较灵活 |
    | 主要优点 | 控制简单、传输效率较高 | 灵活性较高 |
    | 主要缺点 | 对时序配合要求较高 | 控制较复杂，有握手开销 |
  </Accordion>
</AccordionGroup>

## 本章高频考点与易错点

<AccordionGroup>
  <Accordion title="高频考点">
    1. 总线时钟频率与总线工作频率的计算和区别。
    2. 总线带宽的计算，注意 bit/s 与 B/s 的换算。
    3. 总线事务的三个阶段。
    4. 非突发传输与突发传输的地址传送方式和效率差异。
    5. 同步定时与异步定时的特点、优缺点及适用场景。
    6. 不互锁、半互锁、全互锁的握手过程。
  </Accordion>

  <Accordion title="易错点">
    1. **时钟频率 ≠ 工作频率**：前者由时钟周期决定，后者由总线传输周期决定。
    2. **带宽单位**：$W$ 为 bit 时算出 bit/s；要得到 B/s 需除以 8。
    3. **突发传输的计算**：应按一次事务实际传输的数据块总量计算，不能只算一个数据块。
    4. **突发传输只传起始地址**：后续连续数据不需要重复传送地址。
    5. **同步定时依赖统一时钟**：异步定时依赖请求 / 应答握手。
    6. **半互锁与全互锁**：半互锁只有一方等待，全互锁双方都等待信号撤销。
  </Accordion>
</AccordionGroup>

## 本章考前速记

<AccordionGroup>
  <Accordion title="总线性能指标">
    - 时钟频率看时钟周期，工作频率看总线传输周期。
    - 总线带宽与总线宽度、每秒有效传输次数有关。
    - 带宽计算注意 bit/s 与 B/s 的换算。
  </Accordion>

  <Accordion title="总线事务">
    - 地址传送阶段 → 从设备响应阶段 → 数据传送阶段。
  </Accordion>

  <Accordion title="非突发与突发">
    - 非突发：每次传送地址，再传送数据，通常一次一个字。
    - 突发：先传起始地址，再连续传送多个数据字。
  </Accordion>

  <Accordion title="总线定时">
    - 同步定时：统一时钟。
    - 异步定时：握手信号。
    - 异步互锁：不互锁、半互锁、全互锁。
  </Accordion>
</AccordionGroup>
