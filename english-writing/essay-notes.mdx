## 1. 体系总纲

### 1.1 两类材料，一套主体逻辑

| 材料类型 | 第一段 | 第二、三段 |
| --- | --- | --- |
| 图表类 | F1 图表主题 + F2 关键数据关系与规律 | 共用分析和评论框架 |
| 图画类 | F1 画面场景 + F2 关键细节或对比与寓意 | 共用分析和评论框架 |
| 文字材料 | F1 材料主题 + F2 核心观点与意义 | 共用分析和评论框架 |

图表、图画和文字材料真正的区别只在第一段。第二、三段不单独设计新模板。

### 1.2 按题目指令决定功能

| 题目要求 | 应写功能 |
| --- | --- |
| 只要求描述材料 | F1 + F2 |
| 要求描述并解释 | F1 + F2 + F3 |
| 要求描述、解释并评论 | F1 + F2 + F3 + F4 |
| 评论中还要求建议或未来 | F1 + F2 + F3 + F4 + F5 |
| 只要求解释和评论，不要求描述 | F1 简写 + F3 + F4 |

英语一大作文通常包含 `describe`、`interpret`、`comment`，所以 F1 到 F4 是常见组合。F5 不是固定结尾。

### 1.3 推荐篇幅

- 第一段：2 句。
- 第二段：2 到 3 句。
- 第三段：2 到 3 句。

模板只规定“先写什么、后写什么”，不规定每段必须出现多少句型。

## 2. 第一段：材料呈现

### F1 定位材料

**1. 表达目的**

让读者准确知道你看到了什么材料，材料讨论的对象和范围是什么。

**2. 中文表达结构**

图表类：`图表类型 + 调查对象 + 主题 + 时间范围`。

图画类：`画面类型 + 人物 + 动作 + 场景`。

文字材料：`材料类型 + 核心议题`。

**3. 核心英文句型**

图表类：

> The chart above shows `[the topic, group, and time range]`.

多图或组合图：

> The two charts above show `[dimension A]` and `[dimension B]`.

图画类：

> The picture shows `[who is doing what]`.

双幅图：

> The two pictures show two contrasting situations: `[first scene]`, while `[second scene]`.

文字材料：

> The passage above discusses `[the main issue]`.

**4. 填空说明**

- 图表题要写清“谁、什么、什么时间”，例如 `the ownership of major household appliances per 100 households in China from 2014 to 2023`。
- 图画题要写人物、动作和场景，例如 `two climbers on a mountain journey`。
- 双幅图要写两幅图的共同主题或对比关系。
- 不要在 F1 写寓意，寓意留给 F2。

**5. 使用条件与常见错误**

- 单图用 `chart`，多图用 `charts`。
- `from...to...` 只用于材料明确给出的时间范围。
- 图画题不要写成 `The picture illustrates the importance of...`，这是 F2，不是 F1。
- 不要描写与主题无关的背景。

### F2 提取重点并概括

先按图表形式选句型，不要把所有图表都写成同一句：

| 图表形式 | 优先句型 | 限制 |
| --- | --- | --- |
| 比例图、百分比表格、占比柱状图 | `account for X%` | 只写比例，不能接台数或人数 |
| 趋势图、多年份表格 | `rise/fall from X to Y` | 必须有起点和终点 |
| 组合图 | `[attitude clause], while [concern clause]` | 必须写清两图之间的关系 |
| 简单对比柱状图 | `A is higher/lower than B` | 比较对象和单位必须一致 |

**1. 表达目的**

选出最重要的一项数据关系或画面细节，并直接得出趋势、差异或寓意。

**2. 中文表达结构**

图表类：`整体上看 + 一到两个关键数据 + 数据说明的规律`。

图画类：`最关键的细节或对比 + 它暗示的寓意`。

**3. 核心英文句型**

图表比例或排序：

> Overall, `[A]` accounts for `[X]%`, the largest share, while `[B]` accounts for `[Y]%`. This pattern indicates `[main pattern]`.

图表趋势：

> Overall, the figure for `[item]` rose from `[X]` in `[year A]` to `[Y]` in `[year B]`, while `[item 2]` remained relatively stable. This trend indicates `[main pattern]`.

图表组合关系：

> Overall, `[attitude clause]`, while `[concern clause]`. This contrast suggests `[relationship between the two charts]`.

图画单幅：

> The key detail is that `[detail]`. This detail suggests `[meaning]`.

图画双幅：

> The key contrast is between `[A]` and `[B]`: `[A]` `[action or state]`, while `[B]` `[opposite action or state]`. This contrast suggests `[meaning]`.

**4. 填空说明**

- 图表题最多写两到三个数字，不要逐项念数据；组合图要写清两个图之间的关系。
- `[attitude clause]` 和 `[concern clause]` 都要写完整分句，不能只填一个名词。
- `This pattern`、`This trend`、`This contrast` 或 `This detail` 要明确指向上一句内容；后面写规律或含义，不重复数字。
- 图画题的寓意必须从画面细节自然推出，不要跳到大词。
- 如果数据很简单，F2 一句即可完成，不必再加 `Taken together`。

**5. 使用条件与常见错误**

- `account for` 后接比例，不接台数、人数或金额本身。
- `the number of...` 接可数名词，谓语通常用单数。
- `the amount of...` 接不可数名词。
- 趋势必须写起点和终点：`rose from X to Y`，不是 `rose X to Y`。
- 比较数据时对象范围要一致。
- 不要把相关性写成确定因果。用 `This suggests` 比 `which proves` 更稳，也避免关系代词指代不清。

## 3. 第二段：分析原因或意义

### F3 分析链条

**1. 表达目的**

完成一条清晰论证。原因路径说明“什么条件如何影响行为，最终产生材料中的结果”；意义路径说明“某种品质或问题为什么重要，它带来什么影响”。

**2. 中文表达结构**

原因路径：`条件变化 → 人或机构的反应 → 材料中的现象`。

意义路径：`某种品质、行为或问题 → 现实影响 → 为什么值得重视`。

**3. 核心英文句型**

原因路径：

> Because `[specific change]`, `[people or institutions]` are more likely to `[behavior]`. This helps explain `[the material phenomenon]`.

意义路径：

> `[Quality or behavior]` matters because it enables `[people]` to `[effect]`, especially when `[difficult condition]`.

**4. 备用句型**

只有在确实需要说明风险时使用：

> This may also lead to `[specific risk]`.

**5. 填空说明**

- `[specific change]` 要写完整从句，例如 `household income grows`、`the population ages`、`appliances become more affordable`。
- `[behavior]` 要写成人的具体选择，例如购买、使用、提前规划、寻求帮助。
- `[the material phenomenon]` 必须回扣第一段，不能换题。
- 意义路径的 `[effect]` 要写成可观察结果，例如提高效率、减少压力、增强联系。
- `[difficult condition]` 写这种品质或行为真正发挥作用的场景。

**6. 使用条件与常见错误**

- 不要写 `Several factors may account for this phenomenon`，除非下一句真的列出因素。
- `be attributed to` 后接名词或动名词，不接完整句子。
- `contribute to` 表示“促成”，不是“归因于”。
- `give rise to` 表示“导致”，方向是原因到结果。
- 不要连续使用三个 `because`；可用 `one reason is that`、`this means that` 或 `especially when` 变化结构。
- 题目要求解释意义时，可以不写原因，直接走意义路径。

## 4. 第三段：评论与行动

第三段不是固定的“评价 + 建议”。按题目要求选择一条路径：

| 路径 | 使用功能 | 适用情况 |
| --- | --- | --- |
| 只评价 | F4 | 题目只要求评论或表明态度 |
| 评价 + 建议 | F4 + F5 行动 | 题目要求评论并提出解决办法 |
| 只展望 | F5 展望 | 题目要求预测结果或未来趋势 |

### F4 总体评论

**1. 表达目的**

在题目要求 `comment` 时给出明确立场。可以是积极、消极、谨慎或有条件，但必须来自前文分析。

**2. 中文表达结构**

`总体判断 + 核心理由`。需要辩证时，加一句限制或风险。

**3. 核心英文句型**

> In my view, this is `[evaluation]` mainly because `[core reason]`.

需要补充限制时：

> Although `[benefit]`, `[specific risk or condition]` should not be overlooked.

**4. 填空说明**

- `[evaluation]` 可用 `positive`、`concerning`、`a trade-off`、`beneficial under certain conditions`。
- `[core reason]` 必须来自 F3，不能引入新话题。
- `[risk or condition]` 要具体，例如成本、隐私、安全、执行能力。

**5. 使用条件与常见错误**

- 题目不要求 `comment` 时，可以不写 F4。
- 不要用 `Every coin has two sides`。
- 不要重复第一段数据。
- `double-edged` 只有确实同时有明显利弊时才用。

### F5 行动或展望

**1. 表达目的**

题目要求解决、促进或预测未来时，写出具体主体、措施和结果；题目不要求时直接删除。

**2. 中文表达结构**

行动路径：`主体 + 措施 + 预期结果`。

展望路径：`条件 + 可能结果`。

**3. 核心英文句型**

行动路径：

> `[Specific actor]` should `[measure]`, so that `[result]`.

展望路径：

> If `[condition]`, `[positive outcome]` is more likely.

**4. 填空说明**

- 政府：`provide subsidies`、`set safety standards`、`improve regulation`。
- 企业：`lower costs`、`improve safety`、`make products more accessible`。
- 学校：`provide guidance`、`create supportive environments`。
- 个人：`plan ahead`、`seek help`、`develop a habit`。
- 行动主体和措施必须匹配。

**5. 使用条件与常见错误**

- 题目只要求评论时，删除 F5。
- 不要写 `government, schools and individuals should work together`，除非三者都有实际作用。
- 不要用 `Only in this way`。
- 不要把 F5 写成新的论点。

## 5. 语言准确性工具箱

高级词只保留下面这些高频搭配。先保证准确，再考虑升级。

| 功能 | 固定搭配 | 注意 |
| --- | --- | --- |
| 占比例 | `account for X%` | 不接数量本身 |
| 趋势 | `rise/fall from X to Y` | 必须写起点和终点 |
| 稳定 | `remain relatively stable` | 后面不要接具体数字 |
| 比较 | `be higher/lower than that of...` | 比较对象范围一致 |
| 可能 | `be more likely to` | 比绝对因果更稳 |
| 因果 | `help explain`、`lead to` | 回扣材料现象 |
| 作用 | `enable...to...`、`make it possible for...to...` | 后面写具体效果 |
| 评论 | `should not be overlooked` | 用于具体风险或条件 |

### 5.1 最容易失分的地方

1. `number of` 接可数名词，谓语通常用单数；`amount of` 接不可数名词。
2. `rise` 是不及物动词，`raise` 是及物动词。
3. `because` 后接句子，`because of` 后接名词或动名词。
4. `although` 后接句子，`despite` 后接名词或动名词。
5. `account for` 接比例或原因，`contribute to` 表示促成，两者语义不同。
6. `compared with` 表示“与……相比”，`compare A to B` 常表示“把 A 比作 B”。
7. 百分比增加说 `rise by X percentage points`，不同比例的对比说 `compared with X%`。
8. `data` 在正式写作中常视为复数，但为避免争议，优先使用 `the figures show`。

### 5.2 直接删除的表达

- `With the rapid development of society`
- `Every coin has two sides`
- `Only in this way can we`
- `It is universally acknowledged that`
- `More and more people`
- `play an increasingly important role`
- `double-edged sword`

> 如果一句话删掉后不影响论证，它大概率就是空话。

## 6. 可选素材附录

### 6.1 哲理型表达：可直接用于作文的思想表达

这些句子不是名人名言，不标注作者，也不要求加引号。它们是可迁移的思想表达，只在能够总结或深化前文观点时使用。

| 英文表达 | 中文意思 | 适用主题 | 适用位置 | 使用限制 |
| --- | --- | --- | --- | --- |
| Growth rarely comes from comfort; it usually begins where effort meets reflection. | 成长很少来自舒适，它通常始于努力与反思相交之处。 | 个人成长、坚持、学习 | F3 意义路径或 F4 评论 | 不要用于纯数据描述或与成长无关的消费、环境题 |
| Knowledge becomes useful only when it is examined, questioned, and applied. | 知识只有经过审视、质疑和应用，才真正有用。 | 教育、思考、阅读、学习 | F3 意义路径或 F4 评论 | 只用于学习或教育主题，不要硬套到科技、消费题 |
| Technology should expand human capabilities without weakening human responsibility. | 技术应拓展人的能力，而不应削弱人的责任。 | 科技、AI、机器人、创新 | F3 意义路径、F4 评论或 F5 展望 | 只在科技是材料核心时使用 |
| Lasting progress depends on individual effort, but it is strengthened by shared responsibility. | 持久的进步离不开个人努力，也需要共同责任来巩固。 | 合作、社区、公共问题、团队 | F3 意义路径或 F4 评论 | 只有确实涉及多方责任时才用，个人品质题不要硬套 |
| Difficulties do not define a person; the response to them often does. | 困难并不定义一个人，如何回应困难往往才能定义他。 | 挫折、韧性、选择、成长 | F3 意义路径或 F4 评论 | 适合个人成长类图画，不适合政策或纯数据题 |
| What we repeat quietly shapes what we can achieve later. | 我们默默重复的事情，会塑造我们日后能够取得的成就。 | 习惯、时间管理、自律、学习 | F3 意义路径或 F4 评论 | 只用于个人习惯和行为类主题 |
| Material progress is meaningful only when it improves the quality of daily life. | 物质进步只有改善日常生活质量才有意义。 | 消费、生活质量、物质进步 | F3 意义路径或 F4 评论 | 只在消费、生活方式或生活质量是核心时使用 |
| Development is sustainable only when present benefits do not become future costs. | 只有当今天的收益不会变成明天的代价，发展才是可持续的。 | 环境、能源、可持续发展 | F3 意义路径或 F4 评论 | 只用于长期发展、资源或环境问题 |
| Change becomes easier to manage when people are prepared to learn from it. | 当人们准备好从中学习时，变化会变得更容易应对。 | 改变、适应、技术、未来 | F3 意义路径、F4 评论或 F5 展望 | 只在材料涉及变化或适应时使用 |
| A society becomes stronger when progress is measured not only by speed, but by who is included. | 当一个社会的进步不仅以速度衡量，也以谁被纳入来衡量时，这个社会才会更强大。 | 社会公平、公共政策、包容、社区 | F3 意义路径或 F4 评论 | 只用于社会、公共政策或公平议题 |

**使用规则**

- 哲理表达不是必写模块。删掉后不会影响文章结构。
- 一篇作文最多用一句，优先放在 F3 最后一句或 F4 评论中。
- 前半句必须有具体分析，哲理表达只能负责总结或深化，不能代替论证。
- 不用引号，不写作者，不要说 `a famous philosopher once said`。
- 如果一句话不能直接回扣材料主题，就不要使用。
- 如果题目只要求描述或解释，也不必为了“思想深度”强行加入。

**自然接入示例**

F3 意义路径，使用哲理表达：

> People who plan ahead are more likely to finish their work calmly, while those who postpone tasks often create unnecessary pressure for themselves. What we repeat quietly shapes what we can achieve later. In the two pictures, the girl who reads early is not merely finishing a task; she is building a habit of self-discipline.

同一内容，不使用哲理表达：

> People who plan ahead are more likely to finish their work calmly, while those who postpone tasks often face unnecessary pressure. In the long run, this difference affects both efficiency and state of mind.

F4 评论，使用哲理表达：

> Technology should expand human capabilities without weakening human responsibility. For this reason, elderly-care robots should be treated as a supplement to human care, not a replacement for it.

同一内容，不使用哲理表达：

> Elderly-care robots can reduce the burden on working families, but they should not replace human care.

### 6.2 主题词汇：按题积累，不整库背诵

模板笔记只保留最小组块：

- 教育：`acquire knowledge`、`critical thinking`、`lifelong learning`
- 科技：`technological convenience`、`privacy risk`、`digital literacy`
- 社会：`social interaction`、`public awareness`、`community support`
- 经济消费：`disposable income`、`living standards`、`consumption habits`
- 个人成长：`perseverance`、`self-discipline`、`time management`

不要把主题词汇表当成作文模板。真题考什么，再补什么。

## 7. 真题验证

四道题只用于检验五功能是否稳定，不把它们当作“官方范文”。每道题按以下三层区分：

- **材料事实**：来源明确给出的数据、画面或要求。
- **合理推论**：由材料支持的因果或意义解释，但不能写成原始事实。
- **个人评论**：作者立场、建议或未来判断。

来源不确定的 2020 材料已标注为网友回忆版。

### 7.1 2026 英语一：养老机器人双图表

**材料事实**

- 左图：完全接受 39.3%，部分接受 32.8%，拒绝 27.9%。
- 右图：价格是主要关注点，占比 46.3%。
- 要求：简要描述图表、解释图表、发表评论。
- 来源：[搜狐教育解析](https://learning.sohu.com/a/968213401_121118946)、[新华报业网报道](https://www.xhby.net/content/s6946a262e4b011dcdfc37b86.html)。

新华报业网可确认养老机器人主题和双图表形式；具体百分比来自公开解析文章。本文不补造右图其他类别。

**选择功能**：F1 + F2 + F3 + F4；F5 为可选行动或展望。

**英文示范**

The two charts above show consumers' attitudes toward elderly-care robots and their main concerns. Overall, 39.3% of respondents fully accept such robots and 32.8% partly accept them, while price is the leading concern at 46.3%. This contrast suggests that acceptance is broad but conditional.

Because the population is aging and working adults face heavier care burdens, families are more likely to consider robots that offer companionship, health monitoring, and emergency support. This helps explain the growing interest in elderly-care robots. However, if prices remain high, many families may still hesitate to adopt them.

In my view, this is a positive but conditional development. To make these products more accessible, manufacturers should reduce costs and governments should set clear safety standards, so that more older people can benefit without losing essential human contact.

**忠实性与修正**

- 39.3%、32.8%、27.9% 和 46.3% 均来自公开解析。
- “人口老龄化、照护压力、企业降本、政府标准、保留人的陪伴”属于写作分析，不是图表事实。
- 原第一版把 46.3% 写成 `cited by`，本轮改为更稳妥的 `at 46.3%`。
- 原第一版强调“首次双图表”，本轮删除“首次”作为未独立核实的判断。

### 7.2 2025 英语一：主要耐用消费品拥有量

**材料事实**

| 年份 | 空调（台） | 洗衣机（台） | 电冰箱（台） |
| --- | --- | --- | --- |
| 2014 | 75.2 | 83.7 | 85.5 |
| 2017 | 96.1 | 91.7 | 93.3 |
| 2020 | 117.7 | 96.7 | 101.8 |
| 2023 | 145.9 | 98.2 | 103.4 |

单位：全国居民平均每百户年末拥有量。

来源：[2025 英语一真题 PDF](https://m.juyingonline.com/upload/202412/23/202412231030404685.pdf)。

**选择功能**：F1 + F2 + F3 + F4；F5 为可选行动或展望。

**英文示范**

The table above shows changes in the ownership of major durable consumer goods per 100 households in China from 2014 to 2023. Overall, air conditioners rose most sharply, from 75.2 to 145.9, while washing machines and refrigerators increased more modestly, from 83.7 to 98.2 and from 85.5 to 103.4 respectively.

Because household income is growing and appliances are becoming more affordable, families are more likely to buy products that save time and improve comfort. This helps explain the steady rise in ownership. It also suggests that consumers are paying more attention to convenience and quality of life.

In my view, this trend is encouraging because it reflects better living standards. To sustain it, manufacturers should improve energy efficiency and durability, so that more families can enjoy these conveniences without increasing environmental pressure.

**忠实性与修正**

- 所有数字均为原表数据。
- `the figure for...rose from X to Y` 比 `the number of...witnessed an increase` 更准确，因为题目单位是每百户拥有量。
- “收入增长、可负担性提高、节能耐用”属于写作分析，不是原表事实。
- 原第一版中“urban life becomes more demanding”属于无依据泛化，本轮删除。

### 7.3 2019 英语一：登山与坚持

**材料事实**

两个人爬山。一个人坐下说“太累了，不爬了”，另一个人递水并说“休息一下接着爬”。图片下方文字为“旅途”。

来源：[新东方解析](https://kaoyan.xdf.cn/201812/10837501.html)。

**选择功能**：F1 + F2 + F3 + F4；F5 为可选行动或展望。

**英文示范**

The picture shows two climbers on a mountain journey. One sits down and says he is too tired to continue, while the other hands him water and encourages him to rest before moving on. The key contrast is between giving up and continuing. This contrast suggests that perseverance matters when people face difficulty.

Perseverance matters because it enables people to keep making progress when motivation declines, especially when a goal takes a long time to achieve. The second climber's action also suggests that support and a short rest can help someone continue rather than quit.

In my view, this is a valuable lesson. Rather than forcing ourselves to struggle alone, we should set realistic sub-goals and seek support when necessary, so that we can maintain momentum and continue toward our goals.

**忠实性与修正**

- 画面事实来自新东方解析。
- 原第一版“persistence often matters more than momentary strength”略带拔高，本轮改为“motivation declines 时仍能继续前进”，更贴近画面。
- 本题不写社会原因，直接使用意义路径，避免硬套“社会发展”。

### 7.4 2020 英语一：早做与拖延双幅图

**材料事实**

- 第一幅：一个小女孩在看书，文字为“尽早完成才安心”。
- 第二幅：一个孩子瘫坐在沙发上，文字为“不到最后不动手”。
- 主题：习惯、时间管理与拖延。

来源：[哔哩哔哩网友回忆版](https://www.bilibili.com/read/cv4214780)。

该材料是网友回忆版，具体文字应以官方真题为准。本文只用它检验“双幅对比 + 意义分析”结构。

**选择功能**：F1 + F2 + F3 + F4；F5 为可选行动或展望。

**英文示范**

The two pictures show two contrasting attitudes toward daily tasks. In the first, a girl reads with the caption "Finishing early brings peace of mind", while in the second, a child lies on a sofa with the caption "I will not start until the last minute". The key contrast is between planning ahead and postponing tasks. This contrast suggests that time-management habits shape both efficiency and state of mind.

People who plan ahead are more likely to complete their work calmly and carefully, while those who keep postponing tasks often face unnecessary pressure and produce poorer results. This helps explain why good habits matter long before a deadline arrives.

In my view, this is a lesson that deserves attention at an early age. To develop better habits, individuals should divide large tasks into smaller steps and set clear deadlines, so that they can reduce last-minute stress and improve their performance.

**忠实性与修正**

- 两幅图的具体文字来自网友回忆版，已标注不确定性。
- 本题用双幅图对比，不写两段独立画面描述。
- 原第一版“repeated behavior becomes character”过于格言化，本轮删除。
- 第三段只保留具体行动，不再追加空泛未来展望。

## 8. 最终背诵版

### 8.1 五个中文功能

1. **F1 定位材料**：材料是什么，讨论谁、什么时间或什么场景。
2. **F2 提取重点并概括**：最关键的数据或细节是什么，它说明什么。
3. **F3 分析原因或意义**：为什么发生，或者为什么重要。
4. **F4 总体评论**：我的总体判断是什么。
5. **F5 行动或展望**：需要时写具体措施或条件结果。

F1 通常必写；F2 由 `describe` 决定；F3 由 `interpret` 决定；F4 由 `comment` 决定；F5 只在题目需要建议或未来时写。哲理型表达不在必背骨架内；需要时放在 F3 末尾或 F4，最多一句。

### 8.2 图表类骨架

> The chart above shows `[topic, group, time]`. Overall, `[the most important data relationship]`. This pattern indicates `[main pattern]`.

> Because `[specific change]`, `[people or institutions]` are more likely to `[behavior]`. This helps explain `[the phenomenon]`.

> In my view, this is `[evaluation]` mainly because `[reason]`. `[Specific actor]` should `[measure]`, so that `[result]`.

如果题目只要求解释，不要求评论，删除第三段。

### 8.3 图画类骨架

单幅图：

> The picture shows `[who is doing what]`. The key detail is that `[detail]`. This detail suggests `[meaning]`.

双幅图：

> The two pictures show two contrasting situations: `[first scene]`, while `[second scene]`. The key contrast is between `[A]` and `[B]`. This contrast suggests `[meaning]`.

> `[Quality or behavior]` matters because it enables `[people]` to `[effect]`, especially when `[difficult condition]`.

> In my view, this is `[evaluation]`. `[Actor]` should `[measure]`, so that `[result]`.

### 8.4 行动或展望二选一

需要具体措施：

> `[Specific actor]` should `[measure]`, so that `[result]`.

只需要未来展望：

> If `[condition]`, `[positive outcome]` is more likely.

如果题目没有要求建议或展望，直接删除 F5。

### 8.5 考场审题表

| 题目信号 | 处理 |
| --- | --- |
| `describe the chart/picture` | 写 F1 + F2 |
| `interpret the chart/picture` | 写 F3 |
| `give your comments` | 写 F4 |
| 要求措施、建议、未来 | 写 F5 |
| 只要求描述 | 不写 F3、F4、F5 |
| 没有明确原因 | 走意义路径，不编原因 |
| 没有时间写长文 | 至少保留 F1 + F2 + F3 + F4 |

### 8.6 语言检查

- 单图 `chart`，多图 `charts`。
- `account for` 后接比例或原因。
- `number of` 接可数名词，`amount of` 接不可数名词。
- `rise` 不接宾语，`raise` 接宾语。
- `because` 后接句子，`because of` 后接名词或动名词。
- `although` 后接句子，`despite` 后接名词或动名词。
- 趋势句写清 `from X to Y`。
- 比较对象保持一致。
- 用 `This pattern/trend/contrast/detail` 明确指代上一句，再写规律或含义。
- 不用没有把握的哲理表达和高级词。

### 8.7 内容检查

- 第一段是否写清材料对象和范围。
- 图表是否只保留一个主关系。
- 图画是否写清关键细节或对比。
- 第二段是否形成“条件 → 行为 → 结果”或“品质 → 影响 → 意义”的链条。
- 第三段是否只写题目要求的内容。
- 是否误用了“政府、学校、个人共同努力”。
- 删除 F5 后文章是否仍然完整。
- 是否有空泛哲理表达、空泛原因或空泛措施。

### 8.8 最后的写作顺序

1. 读题，圈出 `describe`、`interpret`、`comment`。
2. 判断图表、图画还是文字材料。
3. 用中文写下 F1 到 F4，必要时加 F5。
4. 先填材料和数据，再填原因或意义，最后填评论或行动。
5. 用核心句型连成英文。
6. 检查语法、搭配、数据和逻辑。

> **最终原则**：模板只负责组织思路，不负责替考生思考。写清材料事实，建立一条完整论证链，比背更多句型、哲理表达和高级词更重要。
